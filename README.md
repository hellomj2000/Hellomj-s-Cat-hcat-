# Hellomj's Cat (hcat)
cat program similar to linux "cat"

very simple for learning c++ fstream

![Cat](https://i.redd.it/ya8qikz9kn0f1.png)

### Not actually a real cat thingy btw

cat is the funtion/program that opens a file, read it, and prints it on terminal

## how to use
1. download the file
2. compile hcat.cpp (if you want to)
3. in terminal usage:

   .\hcat.exe filename (e.g. .\hcat.exe sample.txt)

   (or the name of your compiled program)
